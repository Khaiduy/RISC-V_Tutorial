◆ ASCON_HMAC_BLOCKSIZE

#define ASCON_HMAC_BLOCKSIZE   64 /* RFC 2104 compatible block size (matches SHA-256) */

HMAC using Ascon-Hash256

Drop-in replacement for TinyCrypt HMAC-SHA256 HMAC Block Size: Per Ascon specification recommendation: "For backwards compatibility, we recommend SHA-256's block size of 64 bytes." This matches RFC 2104 HMAC construction with SHA-256-compatible block size.
