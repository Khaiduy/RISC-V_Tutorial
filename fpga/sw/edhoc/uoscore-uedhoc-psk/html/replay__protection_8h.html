Re-initialize given replay window based on current sequence number.

This could be used by the user to restore the session. After restoring, replay protection will reject any packet with sequence number that is not greater than the one provided in the argument.

Parameters
current_sequence_number[in] last sequence number that was received before the session was stored
replay_window[out] a pointer to replay window structure
